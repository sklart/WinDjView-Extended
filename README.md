# WinDjView Extended

[![Сборка](https://github.com/sklart/WinDjView-Extended/actions/workflows/build.yml/badge.svg)](https://github.com/sklart/WinDjView-Extended/actions/workflows/build.yml)

**WinDjView Extended** — быстрый и компактный просмотрщик документов DjVu для Windows, написанный на C++ с использованием MFC.

Этот репозиторий является развиваемым продолжением **WinDjView Extended 4.1** от N.M.E., который, в свою очередь, основан на оригинальном **WinDjView** Эндрю Жежеруна.

Цель проекта — сохранить лёгкость, скорость и нативный интерфейс WinDjView, а также дополнительные возможности WinDjView Extended, одновременно модернизируя зависимости, систему сборки, поддержку современных версий Windows, 64-разрядную архитектуру, HiDPI и устойчивость при работе с повреждёнными или некорректными файлами.

## Происхождение проекта

История проекта:

* **WinDjView** — оригинальный просмотрщик DjVu, созданный Эндрю Жежеруном;
* **WinDjView Extended** — расширенная версия, развивавшаяся N.M.E. (`nme3001`) и опубликованная на SourceForge;
* **данный репозиторий** — основан на исходном коде WinDjView Extended 4.1 и содержит дальнейшую модернизацию и исправления.

Исходные проекты:

* [WinDjView Extended на SourceForge](https://sourceforge.net/projects/windjviewextended/)
* [Оригинальный WinDjView](https://windjview.sourceforge.io/)

Первоначальный импорт исходников WinDjView Extended 4.1 в этот репозиторий выполнен коммитом `549daaa`.

## Возможности программы

Проект сохраняет основные возможности WinDjView и WinDjView Extended, в том числе:

* вкладки для одновременной работы с несколькими документами;
* одностраничный, непрерывный и двухстраничный режимы просмотра;
* масштабирование и пользовательские значения масштаба;
* навигацию по страницам;
* отображение оглавления документа;
* миниатюры страниц;
* поиск по текстовому слою DjVu;
* выделение и копирование текста;
* пользовательские закладки;
* аннотации;
* импорт и экспорт закладок и аннотаций;
* расширенную поддержку аннотаций DjVu;
* просмотр метаданных документа;
* обрезку страниц;
* экспорт страницы или выделенной области в изображение;
* прямоугольное выделение;
* расширенные возможности печати;
* сохранение состояния и параметров просмотра;
* поддержку словарей;
* настройки программы и режим работы с конфигурационными файлами, унаследованные от WinDjView Extended.

Исторические проекты Visual Studio 2008 сохранены в репозитории для справки, но для текущей разработки добавлена современная система сборки.

В проекте появились:

* решение для Visual Studio 2022 — `WinDjView.Modern.sln`;
* воспроизводимая сборка через NMAKE;
* полноценные сборки **Win32 и x64**;
* конфигурации **Debug и Release**;
* отдельные библиотеки и PDB-файлы для различных конфигураций;
* автоматическая проверка архитектуры создаваемых PE-файлов.

Поддерживаются четыре основные конфигурации:

| Конфигурация | Архитектура |
| ------------ | ----------- |
| Debug        | Win32       |
| Release      | Win32       |
| Debug        | x64         |
| Release      | x64         |

Подробное описание сборки приведено в [BUILDING.md](BUILDING.md).

## Переход на libjpeg-turbo 3.1.4.1

Устаревшая реализация **IJG JPEG 6b**, использовавшаяся в исходном проекте, заменена на **libjpeg-turbo 3.1.4.1**.

При этом WinDjView продолжает использовать классический интерфейс libjpeg, ожидаемый кодом DjVuLibre.

Интеграция предусматривает:

* статическую линковку;
* сборки Win32 и x64;
* Debug и Release;
* совместимый с libjpeg 6.2 API/ABI;
* отсутствие зависимости от внешней JPEG DLL;
* опциональное SIMD-ускорение через NASM.

По умолчанию NASM для сборки не требуется.

При необходимости SIMD можно включить отдельно.

Подробнее: [docs/libjpeg-turbo.md](docs/libjpeg-turbo.md).

# Совместимость с Windows

WinDjView Extended остаётся **нативным настольным приложением Windows**.

Программа не требует:

* .NET;
* Java;
* Electron;
* Qt;
* отдельной среды выполнения.

Интерфейс построен на Win32 и MFC.

Проект сохраняет ориентацию на Windows 7-era API.

При этом текущая сборка выполняется современным компилятором Visual Studio, поэтому перед выпуском версии с официально заявленной поддержкой Windows 7 необходимо отдельно проверять готовые бинарные файлы на чистых системах:

* Windows 7 x86;
* Windows 7 x64.

Совместимость современных сборок с более старыми версиями Windows, которые могли поддерживаться историческими версиями WinDjView Extended, не гарантируется.

# Сборка

## Требования

Для сборки необходим Visual Studio с компонентами:

* Desktop development with C++;
* MFC;
* MSVC;
* Windows SDK.

Для работы из Visual Studio рекомендуется открыть:

```text
WinDjView.Modern.sln
```

Решение предоставляет конфигурации:

* Debug Win32;
* Release Win32;
* Debug x64;
* Release x64.

---

## Release Win32

```bat
call "C:\Program Files\Microsoft Visual Studio\18\Enterprise\Common7\Tools\VsDevCmd.bat" -arch=x86 -host_arch=x64

cd src\libdjvu
nmake /nologo /f makefile

cd ..
nmake /nologo /f makefile
```

Результат:

```text
src\Release\WinDjView.exe
```

---

## Release x64

```bat
call "C:\Program Files\Microsoft Visual Studio\18\Enterprise\Common7\Tools\VsDevCmd.bat" -arch=x64 -host_arch=x64

cd src\libdjvu
nmake /nologo /f makefile X64=1

cd ..
nmake /nologo /f makefile X64=1
```

Результат:

```text
src\Release_x64\WinDjView.exe
```

Для Debug-сборки необходимо передать:

```text
DEBUG=1
```

Для x64:

```text
X64=1
```

Полная инструкция находится в [BUILDING.md](BUILDING.md).

# Лицензия

WinDjView Extended распространяется на условиях **GNU General Public License версии 2 или более поздней**.

Основной текст лицензии находится в:

```text
src/license
```
