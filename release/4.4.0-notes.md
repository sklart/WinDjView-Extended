# WinDjView Extended 4.4.0

Выпуск 4.4.0 продолжает версию 4.3.0. Доступны отдельные portable-сборки
Win32 и x64 с соответствующими русскими ресурсными DLL.

Для больших страниц добавлен рендеринг областей с ограниченным числом рабочих
потоков (2–4). Готовая страница показывается только после завершения всех её
областей; при неподдерживаемом случае сохраняется прежний полноформатный
рендеринг. Это улучшение рассчитано на большие документы и не меняет качество
изображения. Информационные замеры производительности входят в CI, но не
являются гарантией ускорения каждого документа или компьютера.

В меню «Справка» доступна команда «Проверить обновления». Окно «О программе»
отмечает 64-битную сборку суффиксом `(x64)`. Внутренние изменения кэша и
планирования рендеринга сопровождаются регрессионными проверками.

Автоматическая проверка включает Native MSBuild Debug/Release Win32 и x64,
совместимые NMAKE-сборки, Golden Render, tile geometry/equivalence/scheduler,
многопоточный tile stress, page-cache, BitmapCache, PageWorkingSet,
render-prefetch, thumbnail scheduler, реальный DjVu-корпус, malformed-DjVu
AddressSanitizer, long-path и startup smoke. Для Release проверены PE-архитектура
Win32 `014c` и x64 `8664`, версии EXE и ресурсных DLL, состав архивов и
отсутствие внешних DjVu/JPEG DLL. Контрольные суммы SHA-256 опубликованы вместе
с пакетами.

**Граница проверки:** полный ручной GUI smoke (включая длительную прокрутку,
масштабирование, печать и работу с документом) не завершён. Готовые пакеты не
проверялись на Windows 7 и Windows 10; совместимость с этими версиями Windows
не подтверждается. На Windows 11 проверены запуск распакованных Win32/x64
пакетов и часть интерфейса x64, включая «О программе» и проверку обновлений.

Скачайте архив своей архитектуры; для русской локализации используйте
`WinDjViewRU-Win32.dll` рядом с Win32 EXE или `WinDjViewRU-x64.dll` рядом с
x64 EXE. Лицензия приложения — GPL-2.0; архивы содержат её текст и лицензию
включённого libjpeg-turbo. Обновление особенно полезно при работе с крупными
DjVu-страницами и тем, кому нужна явная x64-сборка.
